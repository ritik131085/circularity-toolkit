# Circularity Toolkit

A practical, neutral-brand toolkit for diagnosing, designing, structuring and optimising circular material systems.

## What is included

- Three entry pathways — build a new system, improve an operating facility, scale a working model
- Ten practitioner modules covering context, feedstock, facility, workforce, processing, quality, markets, economics, risk and scale
- Facility health diagnostic with performance zones and target bands
- Interactive recovery-system planner with CSV and clipboard export
- Six-layer system framework and a six-category risk lens
- Resource-library structure

## Technical notes

The site is a single self-contained `index.html` with no build step and no application dependencies beyond the Inter webfont.

Supported: light and dark themes (follows the OS setting, with a manual toggle persisted to `localStorage`), keyboard navigation, screen-reader improvements, `prefers-reduced-motion`, printing the planner and health-check output, planner CSV/clipboard export, and responsive mobile navigation.

The website is published through GitHub Pages from the `main` branch.

> Planning outputs in the prototype are directional and should not be treated as engineering standards without validated technical inputs.
