# Circularity Toolkit

A practical, neutral-brand toolkit for diagnosing, designing, structuring and optimising circular material systems.

## What is included
- Six-step implementation pathway
- Practitioner tool architecture
- Interactive recovery-system planner
- Circularity system playbooks
- System-health framework
- Resource-library structure

The website is published through GitHub Pages from the `main` branch.

> Planning outputs in the prototype are directional and should not be treated as engineering standards without validated technical inputs.
